### Summary

The requirements trace to R-09 and group B5, and the factual claims check out against the code. `db:start` does not migrate, the identity query reads only, and no CI or docs path calls `setupWorker` other than the README line and the test helpers. Two points should be settled before approval. One is the existing wrong-password test and the new refusal of custom-password stacks. The other is a written note that the password check is the real barrier once `managed` is relaxed. Both have clear fixes, so engineering can proceed.
