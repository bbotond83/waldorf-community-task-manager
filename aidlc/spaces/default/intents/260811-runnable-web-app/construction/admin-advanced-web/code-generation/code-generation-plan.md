# Administrator Advanced Web Code Generation Plan

## Scope

Implement the complete advanced administrator workflows in the existing `/admin` shell using authorized application façade contracts. The unit owns seven-step import/recovery, reminder monitoring/retry, grant governance with immediate revocation, privacy lifecycle, recipient selection, permitted settings, responsive/accessibility behavior, and deterministic synthetic scenarios. It does not own core administrator records/tasks/approvals or any real provider/database/deployment integration.

## Boundaries

- Advanced delivery uses admin façade contracts and shared presentation primitives only; no Supabase/provider client, raw workbook/database aggregate, job store, session store, or domain service import.
- Group Administrator has no import or super-administrator governance capability; Kindergarten Administrator has import/permitted settings but no super-administrator grant controls.
- All data/provider/database effects are invented, deterministic, and labelled synthetic; linked-target evidence remains `OUTSTANDING`.
- No executable deployment workflow or target invocation is added.
