# Entities: U4 Notifications and Excel import

The records U4 owns, in two parts that follow the owning blocks: Notifications (notifications, reminder jobs, their recipients and attempts) and Import (runs, rows, conflicts, the staged payload and the sheet registry). Source: `components.md` (Entity Ownership), ADR-001 to ADR-013, requirements FR4.4, FR5.2, FR7.1 to FR7.3, FR8.1, the confirmed answers Q1 to Q7 in `functional-design-questions.md`, U3's design (BR31.10 hand-off list, ReminderSetting, the audit rule of U1 BR3.2) and the old notification, durable-job, import and advanced-adapter code, and the first architecture review. Conventions from U1 to U3 apply: uuid keys generated by the database, `organization_id` on every table, `version` on records people change at the same time, UTC timestamps, no foreign keys across blocks (typed ids instead).

Two points worth knowing at once. First, the workbook rows are personal data, so the staged payload lives in its own table (`ImportStagedRow`) that only the super admin who started the run can read, and it is emptied after a commit or cancel and at most 7 days after upload (answer Q3); the long-term history (`ImportRow`, `ImportConflict`) holds no names or contact details. Second, delivery of email and SMS is simulated: reminder attempts record a simulated outcome and nothing leaves the machine (FR8.1).

```yaml
entities:
  # ---------------- Notifications ----------------
  - name: Notification
    owner: Notifications
    description: "One message for one parent, shown in the notification list; created inside the use case that causes it (BR40.1) or by the reminder run (BR40.6)"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: parent_id, type: uuid, required: true, constraints: "typed reference to Directory's Parent; readable only by the account linked to that parent" }
      - { name: kind, type: text, required: true, allowed: [sign_up_confirmed, swap_requested, swap_decided, cancellation_decided, place_removed, reminder_7d, reminder_24h] }
      - { name: target_type, type: text, required: true, allowed: [task, change_request] }
      - { name: target_ref, type: uuid, required: true, constraints: "typed id of the Task or ChangeRequest the message is about" }
      - { name: task_id, type: uuid, required: true, constraints: "typed id of the Task the message concerns (for a change request, the requester's task); lets the list build the title and the stale test" }
      - { name: task_starts_at, type: timestamp, required: true, constraints: "the task start when the notice was created; if the task's current start differs, the notice reads as stale" }
      - { name: reminder_job_id, type: uuid, required: false, references: ReminderJob, constraints: "set for reminder kinds only (same block)" }
      - { name: dedupe_key, type: text, required: true, unique: true, constraints: "event notices: kind, target, parent and the assignment or request id with its version; reminders: kind, job, parent and task start; an idempotent replay creates nothing twice, a later genuine repeat (sign up again after cancelling) has a different key" }
      - { name: read_at, type: timestamp, required: false }
      - { name: created_at, type: timestamp, required: true, default: "now (UTC)" }
    constraints:
      - "no names, contacts or notes in the row; the Hungarian title and link are built from the target when the list is read"
      - "inserted only by named functions; a parent may only set read_at on their own rows (BR40.3)"
  - name: ReminderJob
    owner: Notifications
    description: "A planned simulated reminder for one task and one threshold; it serves all recipient families of that task"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: task_id, type: uuid, required: true, constraints: "typed reference to Coordination's Task" }
      - { name: threshold, type: text, required: true, allowed: ["7d", "24h"] }
      - { name: task_starts_at, type: timestamp, required: true, constraints: "the task start the job was planned for; a changed start makes the job stale" }
      - { name: scheduled_for, type: timestamp, required: true }
      - { name: status, type: text, required: true, allowed: [queued, sent, retryable, retrying, stale, cancelled, terminal], default: queued }
      - { name: attempt, type: integer, required: true, default: 0, constraints: "0 to 3" }
      - { name: correlation_id, type: text, required: true, constraints: "a short hash of the task, threshold and start; shown on the reminders screen; contains no family or person id" }
      - { name: version, type: integer, required: true, default: 1 }
    constraints:
      - "unique per task and threshold while the status is not stale or cancelled (one live job per cause)"
  - name: ReminderRecipient
    owner: Notifications
    description: "A family that a reminder job is for"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: reminder_job_id, type: uuid, required: true, references: ReminderJob }
      - { name: family_id, type: uuid, required: true, constraints: "typed reference to Directory's Family" }
      - { name: status, type: text, required: true, allowed: [active, removed], default: active, constraints: "removed when the family's place is removed or moved, or the family is archived, deleted or anonymized" }
    constraints:
      - "unique per job and family"
  - name: ReminderAttempt
    owner: Notifications
    description: "One simulated delivery attempt of a reminder job (for all its active recipients)"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: reminder_job_id, type: uuid, required: true, references: ReminderJob }
      - { name: outcome, type: text, required: true, allowed: [simulated_sent, simulated_retry, simulated_failed] }
      - { name: attempted_at, type: timestamp, required: true, default: "now (UTC)" }
    constraints:
      - "at most 3 attempts per job"
      - "no recipient address or message text is stored; delivery is labelled simulated everywhere"
  # ---------------- Import ----------------
  - name: ImportRun
    owner: Import
    description: "One upload of a workbook through preview, resolution, commit and recovery"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: workbook_name, type: text, required: true, constraints: "the file name only, 1 to 200 characters, no path; shown as the 'Forrás' line" }
      - { name: workbook_fingerprint, type: text, required: true, constraints: "SHA-256 of the staged rows in a fixed order; a commit must present it (BR41.6)" }
      - { name: status, type: text, required: true, allowed: [previewed, confirmed, committed, interrupted, recovered, cancelled, expired], default: previewed }
      - { name: step, type: integer, required: true, allowed: [4, 5, 6, 7], constraints: "the progress step the import screen shows after the upload (steps 1 to 3 are the screen's own file choice and checks)" }
      - { name: total_rows, type: integer, required: true }
      - { name: imported_rows, type: integer, required: true, default: 0, constraints: "created plus updated rows" }
      - { name: skipped_rows, type: integer, required: true, default: 0, constraints: "unchanged rows, keep-existing rows and archived rows (BR41.10)" }
      - { name: started_by_account_id, type: uuid, required: true, constraints: "opaque actor id; only this super admin reads the run's staged rows" }
      - { name: committed_at, type: timestamp, required: false }
      - { name: expires_at, type: timestamp, required: true, constraints: "created_at plus 7 days" }
      - { name: version, type: integer, required: true, default: 1 }
  - name: ImportRow
    owner: Import
    description: "The history of one workbook row: where it came from and what happened to it; no personal data"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: import_run_id, type: uuid, required: true, references: ImportRun }
      - { name: sheet, type: text, required: true, constraints: "one of the 17 registered sheet names" }
      - { name: row_number, type: integer, required: true }
      - { name: source_key, type: text, required: true, constraints: "sheet and row number; the stable identity of the row (1 to 256 characters)" }
      - { name: outcome, type: text, required: true, allowed: [staged, created, updated, skipped, archived, conflict, failed] }
    constraints:
      - "unique per run and source_key"
  - name: ImportStagedRow
    owner: Import
    description: "The parsed workbook row waiting for commit; contains names, contact details and notes, so it is personal data"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: import_run_id, type: uuid, required: true, references: ImportRun }
      - { name: source_key, type: text, required: true }
      - { name: payload, type: jsonb, required: true, constraints: "string values only, each at most 10000 characters; optional-profile text present only when the consent mark is 'igen'" }
      - { name: matched_record_type, type: text, required: false, allowed: [family, task], constraints: "what the row was matched to at preview time" }
      - { name: matched_record_id, type: uuid, required: false }
      - { name: matched_record_version, type: integer, required: false, constraints: "the record's version at preview time; the commit re-checks it (BR41.6)" }
    constraints:
      - "readable only by the super admin who started the run; deletable by that admin and by the system expiry and reset (BR41.7)"
      - "deleted when the run is committed, recovered, cancelled or expired (BR41.8)"
  - name: ImportConflict
    owner: Import
    description: "A row that does not match cleanly and needs the admin's decision"
    attributes:
      - { name: id, type: uuid, required: true, unique: true, default: "database-generated" }
      - { name: organization_id, type: uuid, required: true }
      - { name: import_run_id, type: uuid, required: true, references: ImportRun }
      - { name: import_row_id, type: uuid, required: true, references: ImportRow }
      - { name: row_label, type: text, required: true, constraints: "sheet and row number only (for example 'Családok · 12. sor'), never names" }
      - { name: message, type: text, required: true, constraints: "a fixed Hungarian reason text from a closed list, no personal data" }
      - { name: resolution, type: text, required: false, allowed: [keep_existing, use_import] }
      - { name: version, type: integer, required: true, default: 1 }
  - name: SheetRegistryEntry
    owner: Import
    description: "The fixed list of the 17 workbook sheets with their destination (seeded by migration, not edited by screens)"
    attributes:
      - { name: sheet, type: text, required: true, unique: true }
      - { name: mode, type: text, required: true, allowed: [interactive, read_only_archive] }
      - { name: destination, type: text, required: true }
      - { name: owner_label, type: text, required: true }
    constraints:
      - "exactly the 17 names of the old registry; 8 interactive sheets, 9 read-only archive sheets"
```

## Relationship Summary

- A Parent has many Notifications; a Notification is about one Task or ChangeRequest (typed id, no foreign key) and, for reminders, belongs to a ReminderJob.
- A Task has up to two ReminderJobs (7d and 24h); a job has many ReminderRecipients (families) and up to three ReminderAttempts.
- An ImportRun has many ImportRows, ImportStagedRows (short-lived) and ImportConflicts; a conflict belongs to one ImportRow.
- Cross-block references (Notification to Parent, ReminderJob to Task, ReminderRecipient to Family) are typed ids checked inside the named functions, never foreign keys (ADR-001).
