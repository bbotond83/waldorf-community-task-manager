# Domain Design Plan

The boundary, ownership and interaction choices in this stage are technical and can be resolved from `requirements.md`, `stories.md` and the code knowledge base, so no question is put to the owner here. Each choice is recorded with its alternatives in `decisions.md`, and the owner reviews them at the approval step.

Open defaults the owner can correct at that step: timed checks run daily at 07:00 Budapest time (ADR-006).
