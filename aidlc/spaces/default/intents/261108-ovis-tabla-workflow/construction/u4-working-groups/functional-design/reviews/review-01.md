### Summary

The design is largely sound: C7 and C16 are delivered, traceability is complete, and the member-list visibility matches U3's directory rules without any field leak. It is NOT-READY because four verified gaps would send a developer in the wrong direction. The revoke notice would be silently deduplicated away, the removal block can abort U14 on an order dependency, the concurrency table contradicts the version bump, and an existing writer breaks the membership/grant invariant.
