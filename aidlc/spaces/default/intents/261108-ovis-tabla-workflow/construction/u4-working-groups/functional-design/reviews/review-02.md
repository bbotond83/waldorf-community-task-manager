> R-01 Reviewer note: The once key is now `<kind>:<grant id>` in BR41.6, entities.md (NoticeKind) and W4/W5. This matches `notice_send_core` in 20261050, which de-duplicates on `once key + ':' + parent id`. A test that appoints and then revokes the same grant is required.

> R-02 Reviewer note: BR44.2 now requires U4's block to run before U3's directory block and calls `end_admin` only when an unrevoked grant exists. This fits the code: `identity_end_parent_sign_in` (20261049) clears `parents.account_id`, and `end_admin` aborts with `parent_required` without it. See the new Minor finding about recording this order in the contract.

> R-03 Reviewer note: The concurrency table now follows the rules. The check order in BR40.4 is own, then NOT_A_MEMBER, then VERSION_CONFLICT. BR41.5 includes NOT_A_MEMBER. The refusal table has a separate NOT_A_MEMBER (revoke) row. Appoint/leave and revoke/leave outcomes are consistent with the version bump on appoint and revoke.

> R-04 Reviewer note: BR41.8 and W8 now name `lifecycle_run_core` as a writer and have it end grants before it deletes memberships. See the new Minor finding on how it finds those grants.

> R-05 Reviewer note: BR40.5 gives `end_admin` an optional reason. The detail `grant:group_admin:left_group` matches the audit detail pattern `^[a-z0-9_.:-]*$` (20261012). `end_admin` has no existing callers. See the new Minor finding on the signature change.

> R-06 Reviewer note: BR40.1 now locks the family row, then the parent row, for share, in the removal's lock order, and the concurrency table has the join-while-removal case.

> R-07 Reviewer note: Only the tests that add or set up group-admin grants through `grant_change` are covered. See the new Minor finding for the rest.

> R-08 Reviewer note: BR41.2 maps an archived group to GROUP_UNAVAILABLE, and the NOT_A_MEMBER text no longer says "another group".

> R-09 Reviewer note: BR42.2 moves "counts as shared" and "the email shown" into two helpers and puts `directory_list` on them. The contact rule (own, super admin, teacher, or shared; the email of BR30.6) matches the code in 20261049.
