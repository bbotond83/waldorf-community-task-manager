# Initiative Brief

## Recommendation

**Go to Inception.** Build the three-month, privacy-first MVP for up to 30 families: a Hungarian, role-aware web app on Vercel/Supabase that replaces Excel coordination.

## Approved Basis

Upstream: `intent-statement.md`, `stakeholder-map.md`, `scope-document.md`, `intent-backlog.md`, `competitive-analysis.md`, `feasibility-assessment.md`, `constraint-register.md`, `team-assessment.md`, `wireframes.md`.

The MVP includes role-based coordination, family-owned assignments, signup, swaps, cancellation approval, reminders, admin operations, annual deletion handling, and repeat-safe one-time migration of all 17 legacy workbook sheets. It excludes native apps, SMS/WhatsApp, payments, auto-rotation, new ongoing completion tracking, and live Excel sync; imported legacy status/progress/completion values remain in scope.

## Risks and Plan

Feasibility is conditional/medium-low confidence: resolve GDPR legal basis, annual retention/deletion operations, import mapping/identity/rollback, notification queue behavior, email provider, and provider-region configuration before production. Solo part-time delivery needs privacy-first sequencing and kindergarten-admin decision checkpoints.
