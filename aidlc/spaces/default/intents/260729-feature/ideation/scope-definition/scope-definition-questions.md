## Q1. MVP Delivery Sequence

Which delivery sequence should govern the three-month MVP?

A. Privacy and role foundation first, then parent signup and reminders, then admin operations and import
B. Parent-facing signup first, then administration and privacy hardening
C. Admin operations and import first, then parent-facing flows
D. Another sequence (please specify)

[Answer]: A. Privacy and role foundation first, then parent signup and reminders, then admin operations and import.

## Q2. Scope Cut Rule

If capacity becomes constrained, which capability group can be deferred first?

A. Dashboard refinements and non-essential reporting
B. Excel import
C. Reminder emails
D. No further cuts are acceptable
E. Another rule (please specify)

[Answer]: D. No further cuts are acceptable.

## Q3. MVP Success Check

What must the first release demonstrate before additional capability is added?

A. Families can sign up for and manage responsibilities securely; admins can operate core assignments and send reminders
B. Complete feature parity with the previous spreadsheet workflow
C. A successful import only
D. Another definition (please specify)

[Answer]: A. Families can sign up for and manage responsibilities securely; admins can operate core assignments and send reminders.
