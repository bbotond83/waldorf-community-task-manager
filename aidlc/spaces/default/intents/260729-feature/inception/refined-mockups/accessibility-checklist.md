# Accessibility Checklist

## WCAG 2.2 AA Core Flows

- [ ] Keyboard-only navigation, visible focus, skip link, and logical focus order.
- [ ] Semantic headings, landmarks, labelled controls, and Hungarian error text.
- [ ] Dynamic loading, validation, and outcome status announced accessibly.
- [ ] Non-colour-only status; sufficient contrast; 44×44 px touch targets.
- [ ] Responsive layouts pass 200% zoom and mobile card alternatives retain all actions.
- [ ] Parent duties, requests, admin approval, import, privacy lifecycle, and staff schedules are tested with authorization-denied states.

## Evidence

Automated and manual checks map to the core-flow inventory and user-story acceptance criteria.
