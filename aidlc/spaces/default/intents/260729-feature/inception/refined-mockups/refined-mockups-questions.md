# Refined Mockups Questions

## Q1 — Interaction Pattern

How should approval, swap, cancellation, and import-conflict interactions be presented?

- A. Use dedicated detail views for complex workflows and inline confirmation/error states for simple actions. *(Recommended)*
- B. Use modal dialogs for every workflow.
- C. Use a single wizard for all actions.
- X. Other (please specify)

[Answer]: A — Dedicated detail views for complex workflows and inline confirmation/error states for simple actions.

## Q2 — Responsive Layout

Which responsive behavior should the refined mockups specify?

- A. Mobile-first single-column cards with progressive disclosure; data tables become accessible card summaries. *(Recommended)*
- B. Keep desktop tables at every size.
- C. Provide desktop only.
- X. Other (please specify)

[Answer]: A — Mobile-first single-column cards with progressive disclosure; data tables become accessible card summaries.

## Q3 — Accessibility Target

Which accessibility baseline applies to core flows?

- A. WCAG 2.2 AA with keyboard, focus, semantic landmarks, Hungarian errors, and status announcements. *(Recommended)*
- B. Visual contrast only.
- C. Defer accessibility verification.
- X. Other (please specify)

[Answer]: A — WCAG 2.2 AA with keyboard, focus, semantic landmarks, Hungarian errors, and status announcements.
