# Admin Experience Functional Design Questions

## Q1 — Scope Context

How should an administrator’s active scope be communicated?

- A. Display current organization/group scope on every admin screen and lock group-admin filters to assigned groups. *(Recommended)*
- B. Hide active scope.
- C. Allow unrestricted group selection.
- X. Other (please specify)

[Answer]: A — Display current organization/group scope on every admin screen and lock group-admin filters to assigned groups.
