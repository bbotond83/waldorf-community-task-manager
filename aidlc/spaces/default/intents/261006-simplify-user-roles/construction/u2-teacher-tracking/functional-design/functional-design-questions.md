# Teacher Tracking Design Context

## Confirmed Decisions

The approved inputs settle assigned-group read-only access, authoritative current schedule records, explicit missing owner/assignee/status values, Hungarian Óvónő copy, responsive list/detail parity and safe compatibility redirects. Existing filters, coordination and location remain.

## Ambiguity Analysis

No new product question is required. Calendar validation, allowlist projection, source injection and denial precedence are implementation obligations within the approved contracts. The existing maximum date difference of 31 days is retained; validation additionally requires real YYYY-MM-DD calendar dates. No human answer or interaction-mode selection is fabricated. Summary confirmation and learnings are off.
