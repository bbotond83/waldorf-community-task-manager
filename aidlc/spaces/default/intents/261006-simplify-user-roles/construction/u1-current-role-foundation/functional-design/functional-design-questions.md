# Current-role Foundation Design Context

## Confirmed Decisions

The approved requirements, unit-of-work, unit-of-work-story-map, components and contract-summary define four current roles, group-only read-only Kindergarten teacher access, organization-scoped Super administrator access, state-preserving conversion and fresh selection/sign-in for removed profile cookies. Parent and Group admin permissions remain as specified there. Technical names are English; current Hungarian teacher copy is Óvónő.

## Ambiguity Analysis

No new product question is required for this Unit. Conversion collision behavior, unsupported scope rejection, atomicity and cookie recovery are settled. Repository transaction capabilities, version initialization and enforcement parity are design obligations, not additional product choices. They will be specified in the functional-spec. No interaction-mode question or human answer is fabricated when no question is needed. Summary confirmation and learnings remain off.
