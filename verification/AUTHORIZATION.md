# Authorization and Sensitive-Field Contract

The machine sources are [`authorization-matrix.json`](authorization-matrix.json) and [`sensitive-fields.json`](sensitive-fields.json). Their stable versions are referenced by every verification evidence record.

| Role                                | Permitted scope                                           | Main allow boundary                                                                                        | Required negative boundary                                                                                           |
| ----------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Parent                              | linked family and own requests/assignments                | duties of the whole community, notifications, own contribution, working-group list                         | unrelated family and sensitive fields                                                                                |
| Kindergarten teacher                | whole community                                           | schedule owner/assignee/status and required display names, working-group list                              | every mutation, contact/profile/reason fields, family records                                                        |
| Group Administrator ("Koordinátor") | granted working groups, while the linked parent is active | events, tasks, assignments, approvals and archive of the granted groups; family names only; working groups | other groups' items, community-wide items, family records and contact details, every advanced organization operation |
| Super Administrator                 | organization including governance                         | all approved administration, including family records and working groups                                   | stale/revoked authorization version                                                                                  |

All denials use the same non-enumerating application contract: HTTP 403 where an HTTP response applies, `AUTHORIZATION_DENIED`, no state mutation, no resource-existence signal, and redacted identifier-only evidence. Grant removal, and archiving a parent or family, is effective on the next protected request and clears protected cached navigation/data.

Sensitive contact, locality, optional-profile, protected-reason, participant, and unrelated-family classes are absent from unauthorized projections—not merely hidden in the UI. The dictionary also defines log, audit, fixture, screenshot, report, and lifecycle treatment.

The four current selectable profiles match the runtime catalog. Converted legacy kindergarten administrators use organization-scoped Super administrator workflows, including governance; Parent/Teacher/Group admin direct advanced requests deny. The workbook import no longer exists: `/admin/import` answers "page not found" for every role, and past import audit events stay valid. Old teacher bookmarks are compatibility-only redirects and never create a session. Historical reports remain historical evidence.
