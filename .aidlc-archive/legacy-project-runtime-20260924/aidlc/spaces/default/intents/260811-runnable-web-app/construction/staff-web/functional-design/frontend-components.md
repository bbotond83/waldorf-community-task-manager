## Components

`StaffSchedulePage`, `ScheduleFilter`, `ScheduleTable`, `ScheduleCardList`, `ScheduleDetail`, `AsyncStatePanel`. Props are authorized read-only models. There is no mutation component, action prop, contact field, or raw aggregate.

## Accessibility/Responsive

One H1/main; filter fieldset first; labelled table headers/cards; clear-filter/retry/return actions; denial/error heading focus; polite status announcements; 44×44 targets; card view normative at mobile/200% zoom.
