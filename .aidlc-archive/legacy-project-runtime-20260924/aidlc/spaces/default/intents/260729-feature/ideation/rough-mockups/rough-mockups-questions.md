# Rough Mockups Questions

## Q1. Primary Entry

What should parents see first after signing in?

[Answer]: My Tasks.

## Q2. Visual Direction

What visual character should the Hungarian MVP use?

[Answer]: Warm and calm.

## Q3. Accessibility and Form Factor

Mobile-first responsive web; semantic landmarks, visible keyboard focus, and WCAG-oriented contrast.

[Answer]: WCAG 2.2 AA-aligned mobile-first implementation: semantic HTML, keyboard navigation, visible focus, accessible forms, ARIA only where needed, and screen-reader-readable Hungarian labels/errors.

## Q4. Design System

No existing formal brand system exists. Define a lightweight warm, calm, trustworthy Waldorf-parent-community style using shadcn/ui-compatible tokens and conventions; avoid a full custom brand system.

[Answer]: Confirmed.

## Q5. Core Happy Path and Hierarchy

Parent: My Tasks → assignment detail → sign up or manage change → confirmation and notifications. Admin: dashboard → records/tasks/events → assignments/approvals → import/archive. Global hierarchy: role-aware navigation, page heading, primary action, then supporting content.

[Answer]: Confirmed.
