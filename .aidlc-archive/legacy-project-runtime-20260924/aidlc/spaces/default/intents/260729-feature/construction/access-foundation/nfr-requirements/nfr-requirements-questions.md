# Access Foundation NFR Questions

## Q1 — Authorization Latency

What target should apply to server-side authorization evaluation at expected launch load?

- A. p95 ≤100 ms, with the full protected API response remaining ≤2 seconds. *(Recommended)*
- B. p95 ≤500 ms.
- C. No separate authorization target.
- X. Other (please specify)

[Answer]: A — p95 ≤100 ms, with the full protected API response remaining ≤2 seconds.
