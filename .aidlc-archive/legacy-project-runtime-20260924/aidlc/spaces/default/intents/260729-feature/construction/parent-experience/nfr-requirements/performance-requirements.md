# Performance Requirements

## Targets

Core parent duty pages and actions complete within 2 seconds at normal 30-family load; loading feedback appears immediately without blocking accessible navigation.

## Verification

Measure mobile and desktop p95 page/API performance for duties, signup, swap, cancellation, and notification views.
