# Security Requirements

## Controls

Parent projections contain linked-family data only; request outcomes and notification cards omit contacts, other-family data, and restricted field details. Server authorization protects every action.

## Verification

Test unrelated-parent UI/API denial, stale-version feedback, and notification redaction.
