# Security policy

This is a personal project. If you find a security problem, please report it privately through GitHub:
**Security → Report a vulnerability** on this repository. Please do not open a public issue for it.

All data in this repository is fictitious. If you find anything that looks like real personal data (names, e-mail
addresses, telephone numbers or similar), report it the same way so it can be removed.

There is no warranty and no guaranteed response time.
